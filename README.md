## Entry

**petrichor** — the smell of first rain on dry earth.

Why this word: it is surprising, vivid, and pleasant to say — a single word
that carries a whole scene (dry ground, first rain, that unmistakable smell).
It is 9 characters, inside the 1–24 character gate, and it is not one of the
common words the judge is bored of.

The program writes exactly that one word, lowercase with no trailing
newline, to `/output/entry.txt`.

## Run

```sh
python3 main.py
```
